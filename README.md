# رِواق — بداية المشروع

رِواق منصة عربية لتنظيم اليوم والتعلّم والمشاركة. هذا الإصدار هو **نموذج أولي قابل للتشغيل**:
- واجهة RTL متجاوبة.
- لوحة رئيسية ومهام وإنجازات.
- إضافة المهام وتحديد اكتمالها (محليًا في المتصفح حاليًا).
- نافذة تسجيل دخول SMS جاهزة للربط مع Supabase Auth.
- مخطط SQL أولي للجداول وسياسات RLS.

## 1. المتطلبات

- Node.js 20 أو أحدث (يفضل إصدار LTS).
- npm.
- مشروع Supabase لتفعيل تسجيل الدخول عبر SMS والحفظ السحابي.

## 2. تشغيل المشروع محليًا

```bash
npm install
cp .env.example .env
npm run dev
```

افتح الرابط الذي يظهره Vite في الطرفية، غالبًا `http://localhost:5173`.

## 3. تفعيل Supabase

1. أنشئ مشروعًا في [Supabase](https://supabase.com/).
2. من إعدادات المشروع انسخ Project URL والمفتاح publishable/anon.
3. ضع القيم في ملف `.env`:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY
```

4. من Authentication / Sign In Providers فعّل Phone.
5. اضبط SMS provider وفق تعليمات Supabase والمزوّد المختار، واختبر الإرسال.
6. شغّل `supabase/schema.sql` من SQL Editor.
7. أعد تشغيل خادم التطوير بعد تعديل `.env`.

**مهم:** لا تضع `service_role` أو أي مفتاح سري لمزوّد SMS في ملفات `VITE_*` أو في الواجهة. استخدم فقط المفتاح العام المخصص للعميل، مع RLS مفعّلة.

## 4. ما الذي يعمل حاليًا؟

- التنقل بين صفحات الرئيسية، مهامي، المجتمع، التعلّم، وإنجازاتي.
- إضافة مهمة، وإكمالها، وحذفها من صفحة المهام.
- حفظ المهام في `localStorage` على نفس المتصفح فقط في النسخة الأولية.
- واجهة OTP تستدعي `signInWithOtp` و`verifyOtp` عندما يتم ضبط Supabase.

## 5. ما الذي لم يُربط بعد؟

- المهام لا تزال محفوظة محليًا؛ الخطوة التالية ربطها بجدول `tasks` حتى تظهر للمستخدم نفسه عبر أجهزته.
- صفحات المجتمع والتعلّم معروضة كواجهات تمهيدية، وليست خدمات مكتملة بعد.
- مساعد AI والإشعارات الفعلية تحتاج ربط خدمات خلفية.
- تفعيل SMS الفعلي يتطلب مزوّدًا مدعومًا، وقد يتطلب رصيدًا أو إعدادات تحقق حسب البلد والمزوّد.

## 6. بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

ارفع المشروع إلى مستودع Git ثم اربطه بخدمة نشر تدعم Vite، وأضف متغيرات البيئة من لوحة الاستضافة.

## خطة التنفيذ

1. **المرحلة الأولى:** تشغيل الواجهة واختبار التجاوب.
2. **المرحلة الثانية:** إعداد Supabase وOTP فعليًا.
3. **المرحلة الثالثة:** ربط المهام والملف الشخصي بقاعدة البيانات مع RLS.
4. **المرحلة الرابعة:** تنفيذ المنشورات والتعليقات والإعجابات.
5. **المرحلة الخامسة:** إضافة مساعد AI والتنبيهات، ثم الاختبارات والنشر.
